## Описание лабораторной работы

Цель — самостоятельно реализовать базовые методы работы с массивами (`forEach`, `map`, `filter`, `find`, `some`, `every`, `reduce`) без использования встроенных аналогов. Разрешено использовать только:
- цикл `for`;
- свойство `length`;
- доступ к элементам по индексу;
- метод `push`.

Реализация помогает понять, как работают колбэки и почему эти функции являются «строительными блоками» функционального стиля в JavaScript.

## Краткая документация

В файле `main.js` реализованы следующие функции:

| Функция | Назначение |
| --- | --- |
| `printArray(array)` | Выводит элементы в формате `Element i: value x`. |
| `printArray1(array)` | Выводит элементы в формате `i:  x`. |
| `forEach(array, callback)` | Перебирает массив и вызывает колбэк для каждого элемента. |
| `map(array, callback)` | Возвращает новый массив с результатами вызова колбэка. |
| `filter(array, callback)` | Возвращает новый массив из элементов, для которых колбэк вернул `true`. |
| `find(array, callback)` | Возвращает первый подходящий элемент или `undefined`. |
| `some(array, callback)` | Возвращает `true`, если хотя бы один элемент удовлетворяет условию. |
| `every(array, callback)` | Возвращает `true`, если все элементы удовлетворяют условию. |
| `reduce(array, callback, initialValue)` | Сворачивает массив к одному значению. |

Все функции задокументированы по стандарту JSDoc.

## Примеры использования

```javascript
forEach([1, 2, 3], (element, index) => {
  console.log(`Element: ${element}, Index: ${index}`);
});
// Element: 1, Index: 0
// Element: 2, Index: 1
// Element: 3, Index: 2

map([1, 2, 3], (x) => x * x);            // [1, 4, 9]
filter([1, 2, 3, 4, 5], x => x % 2 === 0); // [2, 4]
find([1, 2, 3, 4, 5], x => x % 2 === 0);   // 2
some([1, 2, 3], x => x > 2);               // true
every([2, 4, 6], x => x % 2 === 0);        // true
reduce([1, 2, 3, 4, 5], (acc, x) => acc + x, 0); // 15
```

## Ответы на контрольные вопросы

**1. В чём преимущества использования колбэков при работе с массивами?**

Колбэки позволяют отделить логику обхода массива от логики обработки каждого элемента. Одну и ту же функцию (`map`, `filter` и т.д.) можно использовать с разной логикой, передавая разный колбэк. Это делает код короче, выразительнее и более универсальным.

**2. Какие проблемы могут возникать при использовании колбэков и как их избежать?**

- «Callback hell» — глубокая вложенность колбэков. Решается через именованные функции, `Promise` или `async/await`.
- Потеря контекста `this` — решается стрелочными функциями или явным `bind`.
- Неочевидный поток управления и сложная отладка — помогает разбиение на маленькие функции и хорошие имена.
- Ошибки внутри колбэка могут «проглатываться» — нужна аккуратная обработка ошибок и проверка типов аргументов.

**3. Как реализовать функции `map`, `filter`, `find`, `some`, `every` и `reduce` без использования встроенных методов массивов?**

Через обычный цикл `for`, обращение к элементам по индексу и метод `push` (см. `main.js`):
- `map` — создаёт новый массив и для каждого элемента кладёт в него результат колбэка;
- `filter` — кладёт в новый массив только те элементы, для которых колбэк вернул `true`;
- `find` — возвращает первый элемент, на котором колбэк вернул `true`; иначе `undefined`;
- `some` — возвращает `true` при первом совпадении, иначе `false`;
- `every` — возвращает `false` при первом несоответствии, иначе `true`;
- `reduce` — заводит аккумулятор и в цикле обновляет его, вызывая колбэк.
