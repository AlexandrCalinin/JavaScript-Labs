## Инструкции по запуску

1. Откройте файл `index.html` в любом современном браузере (двойным кликом или через меню «Открыть в браузере»).
2. При загрузке появится `alert`, после чего откройте DevTools (`F12` → вкладка «Console»), чтобы увидеть вывод.
3. Скрипт также запросит балл через `prompt`.

Также можно запустить `script.js` напрямую в Node.js, но `alert` и `prompt` доступны только в браузере.

## Описание лабораторной работы

Цель — познакомиться с основами JavaScript: подключением скриптов к HTML, работой с переменными, типами данных, условиями и циклами.

В работе:
- создана HTML-страница `index.html` со встроенным и внешним JS;
- внешний скрипт `script.js` объявляет переменные разных типов и выводит их в консоль;
- реализованы условные операторы и цикл `for`.

## Краткая документация

### `index.html`
Главная страница. Содержит встроенный `<script>` с `alert` и `console.log` и подключает внешний файл `script.js` через `<script src="script.js">`.

### `script.js`
- Выводит сообщение через `alert` и `console.log`.
- Объявляет три переменные: `name` (строка), `birthYear` (число), `isStudent` (логическое значение).
- Запрашивает у пользователя балл через `prompt` и проверяет его с помощью `if / else if / else`.
- Демонстрирует цикл `for` — выводит пять итераций в консоль.

## Ответы на контрольные вопросы

**1. Чем отличается `var` от `let` и `const`?**

`var` — старый способ объявления переменной с областью видимости функции, поднимается (hoisting) и инициализируется значением `undefined`. Можно повторно объявить.

`let` — современный способ, область видимости — блок (`{}`). Поднимается, но обращение до объявления вызовет ошибку (temporal dead zone). Повторно объявить в той же области нельзя.

`const` — то же, что `let`, но значение нельзя переприсвоить после инициализации. Для объектов и массивов можно менять содержимое, но не саму ссылку.

**2. Что такое неявное преобразование типов в JavaScript?**

Это автоматическое преобразование значений из одного типа в другой при операциях. Например, `"5" + 1` даёт строку `"51"` (число превращается в строку), а `"5" - 1` даёт число `4` (строка превращается в число). Такое поведение может приводить к ошибкам, поэтому лучше использовать строгие сравнения.

**3. Как работает оператор `==` в сравнении с `===`?**

`==` сравнивает значения с приведением типов (`0 == "0"` → `true`).
`===` сравнивает и значения, и типы без приведения (`0 === "0"` → `false`).
В современной практике рекомендуется использовать `===`, чтобы избежать неожиданного поведения.
