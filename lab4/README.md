## Описание лабораторной работы

Цель — изучить классы и объекты в JavaScript, научиться создавать классы с конструкторами и методами, реализовать наследование и переписать тот же функционал через функции-конструкторы.

Смоделирована простая система инвентаря: базовый класс `Item` (предмет) и наследник `Weapon` (оружие), у которого есть прочность и урон.

## Краткая документация

Файл `main.js` содержит:

### Класс `Item`
- **Поля:** `name`, `weight`, `rarity`.
- **Методы:**
  - `getInfo()` — возвращает строку с информацией о предмете.
  - `setWeight(newWeight)` — задаёт новый вес.

### Класс `Weapon extends Item`
- **Дополнительные поля:** `damage`, `durability` (0..100).
- **Методы:**
  - `use()` — уменьшает прочность на 10 (не уходит ниже 0).
  - `repair()` — восстанавливает прочность до 100.
  - `getInfo()` — переопределён, возвращает расширенную информацию.

### Функции-конструкторы `ItemFn` и `WeaponFn`
Тот же функционал, но через `function` + `prototype`. `WeaponFn` наследует прототип `ItemFn` через `Object.create`.

### Опциональная цепочка `?.`
В тестах используется при доступе к методам объекта, который может быть `null`.

Все функции и методы задокументированы по JSDoc.

## Примеры использования

```javascript
const sword = new Item("Steel Sword", 3.5, "rare");
console.log(sword.getInfo());
// Item: Steel Sword, weight: 3.5, rarity: rare
sword.setWeight(4.0);

const bow = new Weapon("Longbow", 2.0, "uncommon", 15, 100);
console.log(bow.getInfo());
// Item: Longbow, weight: 2, rarity: uncommon, damage: 15, durability: 100
bow.use();        // durability = 90
bow.repair();     // durability = 100

const maybeItem = null;
console.log(maybeItem?.getInfo()); // undefined (нет ошибки)
```

## Ответы на контрольные вопросы

**1. Какое значение имеет `this` в методах класса?**

В методе класса `this` ссылается на конкретный экземпляр, на котором этот метод был вызван (`obj.method()` → `this === obj`). Если метод оторвать от объекта (например, передать как колбэк), `this` может стать `undefined` (в strict mode, который применяется в классах автоматически), и это часто приводит к ошибкам.

**2. Как работает модификатор доступа `#` в JavaScript?**

Префикс `#` делает поле или метод приватным — доступ к нему возможен только изнутри того же класса. Снаружи попытка прочитать `obj.#field` приведёт к синтаксической ошибке. Это настоящая инкапсуляция на уровне языка, в отличие от соглашения с подчёркиванием (`_field`), которое только сигнализирует «не трогай».

**3. В чём разница между классами и функциями-конструкторами?**

- Синтаксис: `class` — современный, лаконичный и читабельный; функции-конструкторы — более старый способ, в котором методы добавляются через `prototype`, а наследование выстраивается вручную через `Object.create` и `Function.call`.
- Поведение: в классах автоматически включается строгий режим, нельзя вызвать класс без `new`, поддерживаются `extends`/`super`, статические поля и приватные `#`.
- Под капотом: классы — это в основном «синтаксический сахар» поверх функций-конструкторов и прототипов; результат во многом эквивалентен.
