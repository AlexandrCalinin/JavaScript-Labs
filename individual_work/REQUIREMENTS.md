Цель проекта
Цель проекта — развить и подтвердить практические навыки программирования на JavaScript, включая работу с DOM, событиями, обработкой данных, пользовательским вводом и организацией кода в модульной структуре. Проект должен показать умение создавать интерактивные, понятные и поддерживаемые интерфейсы без использования сторонних фреймворков.

Основное требование
Разработка веб-приложения или функционального модуля с использованием чистого JavaScript (Vanilla JS).

Функциональные требования
Реализовать работу с DOM: динамическое создание, изменение и удаление HTML-элементов.
Использовать обработчики событий (например, клики, ввод текста, отправка формы и т.д.).
Реализовать валидацию пользовательского ввода и вывод понятных сообщений об ошибках.
Выполнить работу с массивами объектов:
отобразить список элементов (например, товаров, пользователей, книг и т.п.),
реализовать фильтрацию, сортировку или поиск по этим данным.
Обеспечить удобный и адаптивный интерфейс, ориентированный на пользователя.
(Опционально) Включить взаимодействие с внешним API для загрузки или отправки данных.
Добавить интерактивные элементы (например, вкладки, модальные окна, анимации, dragNdrop), улучшающие пользовательский опыт.
Нефункциональные требования
Использование ES6+ синтаксиса и возможностей JavaScript.
Структурирование кода с использованием модульного подхода.
Код должен быть оформлен с соблюдением принципов читаемости: осмысленные названия переменных и функций, комментарии при необходимости.
Страница должна быть стилизована с использованием CSS, обеспечивая приятный и современный внешний вид.
Подготовить краткую документацию (README.md) с инструкцией по запуску и кратким описанием проекта.
Максимальное количество участников в одном проекте — 2 человека. Возможность работы в паре согласуется с преподавателем и зависит от объёма и сложности выбранной темы.

Примеры возможных тем
To-Do List: создание списка задач с возможностью добавления, удаления, редактирования, поиска и фильтрации по статусу.
Планировщик расписания: отображение событий, редактирование и фильтрация по дате/категории.
Калькулятор: создание простого калькулятора с возможностью выполнения базовых арифметических операций.
Галерея изображений: отображение изображений с возможностью фильтрации, сортировки и просмотра в полноэкранном режиме.
и другие.
