## Инструкции по запуску

Из-за использования ES-модулей (`type="module"`) нельзя открывать `index.html` напрямую через `file://` — браузер заблокирует загрузку модулей. Нужен любой локальный HTTP-сервер.

### Через `npx` (требуется [Node.js](https://nodejs.org/))

```bash
cd lab5
npx serve .
```

После запуска откройте в браузере адрес, который выведет команда (обычно `http://localhost:3000`).

Альтернативный вариант:

```bash
npx http-server . -p 8080 -o
```

## Описание лабораторной работы

Цель — изучить взаимодействие JavaScript с DOM-деревом на примере небольшого веб-приложения для учёта личных финансов.

В приложении можно:
- добавлять транзакцию через форму (сумма, категория, описание);
- видеть список транзакций в таблице с краткой версией описания (первые 4 слова);
- удалять транзакцию кнопкой в строке (используется делегирование событий);
- видеть общую сумму всех транзакций;
- кликнуть по строке таблицы и увидеть полное описание транзакции;
- получать сообщение об ошибке, если форма заполнена некорректно.

Положительные суммы подсвечиваются зелёным, отрицательные — красным.

## Краткая документация

### `src/utils.js`
- `generateId()` — уникальный идентификатор транзакции.
- `formatDate(date)` — форматирует `Date` в строку `YYYY-MM-DD HH:mm`.
- `shortDescription(str, n)` — возвращает первые `n` слов строки (по умолчанию 4).

### `src/transactions.js`
- `transactions` — массив транзакций.
- `addTransaction(data)` — создаёт объект транзакции, добавляет в массив и возвращает его.
- `deleteTransaction(id)` — удаляет транзакцию по `id`.
- `findTransaction(id)` — ищет транзакцию.
- `calculateTotal()` — возвращает общую сумму.

### `src/ui.js`
- `renderTransactionRow(t)` — добавляет строку в таблицу. Применяет класс `positive` или `negative`.
- `removeTransactionRow(id)` — удаляет строку.
- `updateTotal(total)` — обновляет блок с общей суммой.
- `showDetails(t)` — показывает полную информацию о транзакции под таблицей.
- `clearDetails()` — очищает блок подробного описания.

### `src/index.js`
Связывает форму и таблицу:
- слушает `submit` формы, валидирует поля и добавляет транзакцию;
- один обработчик `click` на таблице обрабатывает и удаление (по кнопке), и показ деталей (по строке).

Все функции задокументированы по JSDoc.

## Примеры использования

1. Запустите проект и откройте страницу.
2. Введите в форму: сумма `1500`, категория `Salary`, описание `Зарплата за май 2026 первая часть выплаты`. Нажмите «Добавить» — в таблице появится зелёная строка с текстом «Зарплата за май 2026».
3. Введите: сумма `-200`, категория `Food`, описание `Ужин в кафе с друзьями вечером`. Появится красная строка.
4. Кликните на строку — под таблицей появится полное описание.
5. Нажмите «Удалить» — строка и транзакция удалятся, сумма пересчитается.
6. Попробуйте отправить пустую форму — появится сообщение об ошибке.

## Ответы на контрольные вопросы

**1. Каким образом можно получить доступ к элементу на веб-странице с помощью JavaScript?**

Через методы `document`:
- `document.getElementById(id)`;
- `document.querySelector(selector)` / `document.querySelectorAll(selector)`;
- `document.getElementsByClassName` / `getElementsByTagName`.

Также можно идти от уже найденного элемента: `el.querySelector`, `el.children`, `el.parentElement`, `el.closest(selector)`.

**2. Что такое делегирование событий и как оно используется для эффективного управления событиями на элементах DOM?**

Делегирование — это приём, когда обработчик навешивается не на каждый дочерний элемент, а на общего родителя, и внутри обработчика определяется, по какому именно элементу был клик (через `event.target` / `event.target.closest()`).

Плюсы:
- меньше обработчиков → ниже потребление памяти;
- работает и для новых элементов, добавленных позже;
- удобно для динамических списков (как таблица транзакций в этой лабе).

В проекте один обработчик на `<table>` отвечает и за удаление, и за показ деталей.

**3. Как можно изменить содержимое элемента DOM с помощью JavaScript после его выборки?**

- `element.textContent = "..."` — безопасно меняет только текст.
- `element.innerHTML = "..."` — меняет HTML-содержимое (осторожно с XSS).
- Для атрибутов — `setAttribute` / прямой доступ к свойствам (`el.value`, `el.src`).
- Для классов — `element.classList.add/remove/toggle`.
- Для стилей — `element.style.color = "red"`.

**4. Как можно добавить новый элемент в DOM-дерево с помощью JavaScript?**

1. Создать элемент: `document.createElement("tr")`.
2. Настроить его (текст, классы, атрибуты, обработчики).
3. Вставить в дерево:
   - `parent.appendChild(child)`;
   - `parent.append(child1, child2, "text")`;
   - `parent.insertBefore(newNode, referenceNode)`;
   - `element.insertAdjacentHTML("beforeend", "<tr>...</tr>")`.
